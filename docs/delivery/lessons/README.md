# Delivery Lessons

Process and delivery lessons written by `/nxs.close` when an epic closes.

## Convention

One file per lesson: `<date>-<slug>.md`, where `<date>` is `YYYY-MM-DD`.

Each file carries the source epic in its frontmatter:

```markdown
---
date: 2026-09-05
source-epic: "#42"
---

# <Lesson title>

...
```

One lesson per file. Do not append a second lesson to an existing file, and do not
maintain an index — the directory listing is the index.

These are lessons about **how the work went** — planning, sequencing, review, tooling.
Lessons about *what the system is* belong in the concept store, written by `/nxs.distill`.
